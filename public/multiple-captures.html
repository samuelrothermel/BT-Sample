Test Overview

This page allows you to test whether Pay Later authorizations support multiple partial captures. The workflow is:

  1. Create a Pay Later authorization (without submitting for settlement)
  2. Attempt multiple partial captures against the same authorization
  3. View results to confirm if multiple captures are supported
Note: PayPal typically requires authorizations to be captured within 3 days. Test multiple captures immediately after authorization.
