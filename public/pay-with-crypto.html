ℹ️ How Pay with Crypto Works

Integration type: Local Payment Method using createLocalPaymentContext GraphQL mutation + localPayment.startPayment()

Flow:

  1. Client sends buyer details & amount to merchant server
  2. Server calls Braintree GraphQL createLocalPaymentContext → gets approvalUrl
  3. Client SDK calls localPayment.startPayment({ paymentType: 'crypto', cryptoOptions: { approvalUrl } })
  4. Full-page redirect to PayPal crypto approval UI
  5. Buyer approves → redirected back with a paymentMethodNonce
  6. Merchant server calls /api/crypto-sale to settle

Requirements: SDK v3.137.0+, crypto-enabled merchant account, crypto merchant account ID (e.g. CRYPTO_USD).

Settlement: Automatic in local currency or PYUSD. Refunds use standard Braintree Transactions API.

Webhooks: Listen for LOCAL_PAYMENT_COMPLETED for payment confirmation.
