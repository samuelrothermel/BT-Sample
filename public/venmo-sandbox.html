Enablement gates & testing notes
  1. Send your Sandbox Public ID (shown below) for Venmo whitelist + profile ID issuance. Testing will fail until that is confirmed.
  2. Wire client with enableVenmoSandbox: true, profileId, paymentMethodUsage: 'single_use', desktop QR + mobile web fallback.
  3. Authorize only (submit_for_settlement: false); capture later. Amounts must be USD.
  4. Sandbox captures do not debit the test Venmo balance — confirm via transaction status/IDs.
  5. Venmo authorizations hold ~10 days before expiring.

Compliance: show an order summary pre- and post-purchase (items, total, Venmo, customer name + Venmo username).
