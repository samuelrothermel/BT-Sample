ℹ️ About Vaulted Token Transactions

What is this?

This page demonstrates processing new sale transactions using previously vaulted payment method tokens. This is useful for:

  • ACH Transactions: Use verified ACH tokens for instant transactions (bypasses network check verification)
  • Recurring Payments: Charge saved credit cards or bank accounts
  • One-Click Checkout: Use stored payment methods without re-entering details
  • Subscription Renewals: Automatic charges to stored payment methods

How to get a token:

  1. Visit any vaulted payment demo page (e.g., Hosted Fields Vaulted or ACH Only)
  2. Complete a transaction with vaulting enabled
  3. Copy the payment method token from the success message
  4. Return to this page and paste the token below

Benefits:

  • ✅ No verification required (already verified during initial vault)
  • ✅ Faster transaction processing
  • ✅ Better user experience (no re-entry of payment details)
  • ✅ Works with all payment methods (cards, ACH, PayPal, Venmo, etc.)

🧪 Need Test Tokens?

To get test tokens:

  1. ACH Token: Go to ACH Only page, complete a transaction, and copy the token
  2. Credit Card Token: Go to Hosted Fields Vaulted, pay with card, and copy the token
  3. PayPal Token: Same as credit card, but use PayPal option

Note: Tokens are specific to your Braintree sandbox environment and cannot be shared.

⚠️ Sandbox Mode: This is a test environment. No real money will be charged.
